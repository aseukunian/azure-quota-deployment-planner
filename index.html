Azure Quota & Usage Report

Pulls quota limits vs. current usage for a subscription straight from the public Azure Resource Manager API — the same numbers the Portal shows, as a shareable report. Includes the modern Microsoft.Quota unified provider (multi-RP) and pending quota-increase requests.

Quota scopes to query

Service-specific quota APIs return only their documented counters. Pending-request history is queried only for the existing Microsoft.Quota scopes. Dev Box includes Dev Center counters; Container Apps and Search report regional quotas, not every resource-level limit.

AVS is opt-in and uses a read-only quota-check POST requiring Microsoft.AVS/locations/checkQuotaAvailability/read (normally included in Reader). Subscription access and service availability still apply. It returns remaining hosts, not usage percentages; this tool never grants permissions or requests increases.

 Zone mapping 

      
Azure assigns logical zone numbers (1, 2, 3) independently per subscription — two subscriptions' “Zone 1” can map to different physical datacenters. Pick a region to see each subscription's logical→physical zone mapping (availabilityZoneMappings).

 Include SKU availability & restrictions?

    

      This option queries the Azure Compute SKUs API once for every region you fetch, which adds roughly 5 seconds per region to the run. On a large multi-region query the fetch will take noticeably longer. It is worth it when you need to know which VM sizes you can actually deploy (not just your quota), otherwise you can leave it off.
